# Portfolio Website

A personal portfolio website that showcases my projects, skills, and contact information in one place.

## Overview

This portfolio is designed to present my work in a clean, professional, and responsive way. It highlights my coding projects, technical interests, and links for people who want to learn more about me.

## Features

- Responsive layout for desktop and mobile
- Project showcase section
- Skills / technologies section
- About me section
- Contact or social links
- Clean and simple UI

## Tech Stack

- HTML
- CSS
- JavaScript

## Project Structure

- `index.html` — main website structure
- `style.css` — styling and layout
- `script.js` — interactive behavior

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/plainaditya/Portfolio-Website.git
```

### 2. Open the project

Open `index.html` in your browser, or use a local development server.

### 3. Edit content

Update the project cards, skills, about text, and contact links with your own information.
